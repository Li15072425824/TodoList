第一幕 · 它是什么Definition
2026.09
命令行名字叫 dsh
官方出品，一切皆插件
DeepSeek Harness（CLI 命令 dsh）位于 deepseek-ai 官方组织下，与 DeepSeek-V3/R1 同属一个 org；npm 包 @deepseek-ai/dsh 由 DeepSeek 维护者发布。
口号是 "Everything is a Plugin"，构建在源自 Koishi 生态的 Cordis 插件框架之上；官方 API 文档宣布其处于 developer preview 阶段，并有独立文档站 deepseek-harness.github.io。
⚠️ 官方明确警告会有 breaking changes——项目年轻、迭代快，接口与文档可能快速变化。README · API-DOCS

两条安装使用路径
Node 起 UI，Python 起 SDK
PATH A · NODE / NPM
Web UI 入口
npx @deepseek-ai/dsh web
启动 Web UI（默认 127.0.0.1:3080）并自动打开浏览器；也可 clone 后 pnpm install / build 从源码运行。
PATH B · PYTHON SDK
pip 即装即用
pip install deepseek-harness-sdk
需 Python 3.10+；自带平台原生运行时 wheel 与 dsh 命令，无需系统 Node.js；支持 Linux x64/arm64、macOS arm64、Windows x64。
Python 侧配置走环境变量：DEEPSEEK_API_KEY / 可选 DEEPSEEK_BASE_URL；示例：DeepSeekHarness(provider="deepseek-official", model="deepseek-v4-flash", max_tokens=49_152, ...)

第三幕 · 架构方案Architecture
2026.09
Cordis 插件树
连 Agent Loop 都是插件
dsh 没有任何特权核心：模型适配器、工具注册表、会话日志乃至 agent loop 本身，都是可从配置替换的插件。运行时在启动时按有序层组合出一棵 Cordis 插件树。
扩展方式是在插件树旁挂载新插件；注册项是插件卸载时自动回卷（unwind）的 effect——不做侵入式补丁，天然可拆卸。

第三幕 · 架构方案Agentic Loop
2026.09
turn / step 两层抽象
一个 Turn，多个 Step
step = 一次模型请求 + 它调用的工具；turn = 零个或多个 step（首个输入被认领前开启、无欠账时关闭）。一次 turn 的内部流程：
TURN FLOW · turn/start → turn/end
i.
组装
prompt 段与工具 schema 组装
ii.
请求
agent / request 准备调用
iii.
流式
llm / stream 流式输出
iv.
执行
tool / call 执行工具
v.
回填
tool / result 返回结果，进入下一 step
可持久化的 session 事件：turn/* · step/* · system/message · user/message · assistant/message · tool/* —— 会话以未压缩 JSONL 存于 <dsh_home>/sessions按 Space / → 逐步推进 · docs/architecture.md
