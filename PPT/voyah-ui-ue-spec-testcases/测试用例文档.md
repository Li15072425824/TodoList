# Voyah UI/UE 规范符合性测试用例文档

> **被测对象依据**：MasterGo 设计稿「全局UI样式标准」
> （fileId 192726801132881，page M，共 12 个规范模块：间距 / 线条 / 图标 / 按钮 / 字体 / 色彩×7 主题）
> **测试目标**：验证实现产物（demo 页面 / 前端代码）是否严格符合该 UI/UE 规范
> **用例统计**：TC-0 通用 ×4，TC-1 色彩 ×14，TC-2 字体 ×10，TC-3 间距 ×8，TC-4 线条 ×8，TC-5 按钮 ×16，TC-6 图标 ×8，共 **68 条**
> **优先级定义**：P0 = 阻断性（错了不能交付）；P1 = 重要；P2 = 建议性

---

## TC-0 通用 / 跨模块规则

| 编号 | 优先级 | 检查项 | 预期结果 / 判定方法 |
|---|---|---|---|
| TC-0-01 | P0 | 设计 Token 化 | 颜色、间距、字体、阴影均通过 CSS 变量引用，禁止在组件样式中硬编码十六进制值（审查 computed style） |
| TC-0-02 | P0 | 尺寸与距离 4px 倍数 | 所有组件尺寸与间距均为 4 的倍数；DevTools 检查不得出现 6px、9px、11px 等非 4 倍数值（圆角 6px、线宽 0.5~3px 这类规范明确豁免值除外） |
| TC-0-03 | P1 | 主题色切换一致性 | 切换 7 套主题色（蓝/红/黄/绿/紫/翠青/碧青）时，仅主色系 token 变化，中立色/辅助色/间距/字体等其余规范值不变 |
| TC-0-04 | P1 | 状态矩阵完备性 | 每个可交互组件均实现 Normal / Hover / Click / Disabled 四态，不允许缺态或态之间颜色混用 |

## TC-1 色彩规范

**规范值速查（依据设计稿「色彩-蓝色」页 + 各主题页）：**

- 中立色-字体：`#111111`(Title) `#333333`(Primary) `#666666`(Secondary) `#999999`(Caption) `#C1C1C1`(Disable/icon hover)
- 中立色-线条：`@line1-1 #EBEBEB` `@line1-2 #DEDEDE` `@line1-4 #737373` `@line-Blue #3773DB`，以及 `#888888`（默认图形 icon）
- 中立色-填充：`@filling1-1 #FAFAFA` `@filling1-2 #F3F4F7` `@filling1-3 #F5F5F5`
- 辅助色 4 阶（常规/按下4/hover2/浅色1）：
  - 成功：`#00D115` / `#00A611` / `#A8E1A6` / `#E3F8E8`
  - 警告：`#FFA800` / `#EA8C00` / `#FFD77E` / `#FFF1DB`
  - 错误：`#FF2020` / `#CF2E2E` / `#FDA2A4` / `#FCEBEA`
  - 帮助：`#54A7B2` / `#38929F` / `#A6D2D8` / `#E8F6F9`
  - 紫：`#8F44FF` / `#5000C8` / `#D0B0FF` / `#F5EFFF`

| 编号 | 优先级 | 检查项 | 预期结果 |
|---|---|---|---|
| TC-1-01 | P0 | 字体颜色 5 级取值 | 标题/正文/辅助/提示/禁用文字分别使用 #111/#333/#666/#999/#C1C1C1，无取值溢出（特殊场景仅允许 #222/#444/#555/#888） |
| TC-1-02 | P0 | 线条颜色 5 级与语义 | 分割线/边框按层级用 #EBEBEB→#3773DB，重要程度越高颜色越深；表单边框 #DEDEDE，hover #737373 |
| TC-1-03 | P0 | 填充色 3 级与语义 | #FAFAFA=页面内容区块底色，#F3F4F7=标签背景/下拉选中背景，#F5F5F5=提示框底色 |
| TC-1-04 | P0 | 辅助色语义正确 | 成功=提交确认、警告=事件提醒（#FFA800 为主）、错误=失败报错（#FF2020）、帮助信息用 Help 色，不得混用 |
| TC-1-05 | P0 | 辅助色 4 阶用法 | 每组辅助色：3 号=常规、4 号=按下、2 号=hover、1 号=浅色背景，按钮/提示框对应正确 |
| TC-1-06 | P0 | 主色序列 4 阶 | 主色：常规 #3773DB、按下 #1C5AC4、hover #568EEE、浅色 #ECF3FF；「后续组件示例皆以此色为主色调」 |
| TC-1-07 | P1 | 主题色 7 套完整 | 红/黄/绿/紫/翠青/碧青主题各自的主色序列 4 阶值与设计稿对应页一致（对照各色彩页 DSL） |
| TC-1-08 | P1 | 色值无近似替代 | 不允许出现近似色（如 #3774DB、#FAFBFA）；逐字符比对十六进制值 |
| TC-1-09 | P2 | 半透明色用法 | 仅设计稿定义的 rgba 值可用（如 rgba(128,163,203,0.4)），不得自造透明度 |

## TC-2 字体规范

**规范值速查（「字体」页）：**

- 字体族：中文首选 PingFang SC（Mac/iOS），备选 Microsoft YaHei（Windows）/ HarmonyOS Sans；英文首选 Helvetica Neue，备选 Arial / Inter；数字展示 D-DIN
- 字重：Regular 400 / Medium 500 / Bold 600，仅此三种

| 文字层级 | 字号 | 行高 | 场景 |
|---|---|---|---|
| 页面大标题 | 18~24px | 32~40px（1.6~1.7） | 页面顶部标题、重要数据展示 |
| 模块小标题 | 16px | 24~28px（1.5~1.75） | 卡片标题、弹窗标题 |
| 正文（主字号） | 14px | 22px（1.57） | 表单、表格、按钮、常规段落、左侧导航 |
| 大段描述 | 14~16px | 24~28px（1.6~1.75） | 帮助文档、详情页说明 |
| 辅助说明 | 12~13px | 20px（1.5~1.67） | 提示文字、备注、时间戳 |

| 编号 | 优先级 | 检查项 | 预期结果 |
|---|---|---|---|
| TC-2-01 | P0 | 字体族 fallback 链 | font-family 含 PingFang SC 与 Microsoft YaHei，声明顺序与设计稿首选/备选一致 |
| TC-2-02 | P0 | 字重仅 400/500/600 | 全局无 300/700 等其他字重；数字展示组件使用 D-DIN（或其 fallback） |
| TC-2-03 | P0 | 六级文字层级映射 | 每类场景文字的 font-size/line-height 落在上表区间内，且同类场景取值统一（不得同页面两种"正文"字号） |
| TC-2-04 | P0 | 正文主字号 = 14px | 表格、表单、按钮、导航文字均为 14px/22px，行高偏差为 0 |
| TC-2-05 | P1 | 行高使用倍数 | line-height 按推荐倍数或固定 px 值设置，不允许出现规范外倍数（如 1.3、2.0） |
| TC-2-06 | P1 | 禁用文字颜色联动 | Disabled 文字 #C1C1C1 与字体色 5 级中 Disable 档一致（跨模块一致性） |
| TC-2-07 | P2 | 不做字号归一化 | 实现忠实于设计稿字号，不得为"好看"擅自放大/缩小标题字号 |
| TC-2-08 | P2 | letter-spacing | 设计稿标注 auto 的文字不得显式设置 letter-spacing |

## TC-3 间距规范

**规范值速查（「间距」页）：**

- 规则：`Sn = 4px × n`，S1~S20 = 4~80px；常用 S2(8)/S3(12)/S4(16)/S6(24)
- 组件间间距 8px；输入框内容 padding 12px；按钮左右 padding 16px

| 页面/弹窗区域 | 左 | 右 | 上 | 下 |
|---|---|---|---|---|
| 导航 | 24 | 24 | — | — |
| 页面内容 | 24 | 24 | 16 | 24 |
| 弹窗 | 24 | 24 | — | — |
| 卡片 | 16 | 16 | 16 | 16 |
| 输入框内容 | 12 | 12 | 6 | 6 |

| 编号 | 优先级 | 检查项 | 预期结果 |
|---|---|---|---|
| TC-3-01 | P0 | 间距只取 S1~S20 | 所有 margin/padding/gap 值 ∈ {4,8,12,…,80}，无 6/9/11 等非法值（豁免：输入框上下 6px、按钮圆角 6px） |
| TC-3-02 | P0 | 四种常用间距 | 元素亲密性对应的间距使用 8/12/16/24px，相关性越强间距越小 |
| TC-3-03 | P0 | 组件间间距 8px | 相邻独立组件（按钮组、表单项之间）垂直/水平间距 = 8px |
| TC-3-04 | P0 | 输入框内边距 | input 内容区 padding 12px（左右）× 6px（上下） |
| TC-3-05 | P0 | 按钮左右 padding | Large/Middle 按钮「文字+左右 16px」，Small 按钮「文字+左右 8px」 |
| TC-3-06 | P1 | 页面级 Padding | 导航左右 24；页面内容 24/24/16/24；弹窗 24；卡片四边 16，逐项与上表比对 |
| TC-3-07 | P1 | 纵向/横向间距示例 | 对照设计稿「弹框标题/Option A-D/提交」示例：弹窗内标题与内容 24px、选项间 8~12px、按钮区右对齐等排布关系一致 |
| TC-3-08 | P2 | 不出现魔法数 | 间距不允许出现 S1~S20 之外的值（如 10px、15px、100px） |

## TC-4 线条规范

**规范值速查（「线条」页）：**

- 粗细：实线 0.5px / 1px / 2px / 3px；虚线同样分档（line 1~3）
- 颜色层级：一级 #EBEBEB → 二级 #DEDEDE → 三级 #888888 → 四级 #737373 → 五级 #3773DB（越重要越深）
- 文字分割线：水平（文字两侧等宽线段）与垂直（线段居文字上下）两种，线段长 74px、高 12px 间距

| 编号 | 优先级 | 检查项 | 预期结果 |
|---|---|---|---|
| TC-4-01 | P0 | 线宽合法值 | 所有 border/分割线宽度 ∈ {0.5, 1, 2, 3}px，无 1.5px、4px 线宽 |
| TC-4-02 | P0 | Line 1 语义 | 常规分割线/边框用 1px + #EBEBEB 或 #DEDEDE |
| TC-4-03 | P1 | 层级越深越重 | 五级线条颜色逐级加深，hover 用 #737373（四级）或 #3773DB（五级/较重要） |
| TC-4-04 | P1 | 虚线样式 | 虚线按钮/虚线边框为 dashed，粗细与虚线规范档位一致 |
| TC-4-05 | P1 | 水平文字分割线 | 「文字——分割线——文字」两侧线段等宽（各 74px），垂直居中 |
| TC-4-06 | P1 | 垂直文字分割线 | 线段上下对称、高度 12px，位于文字上方与下方 |
| TC-4-07 | P2 | 分割线不喧宾夺主 | 页面主要结构使用 Line 1/2（细/常规），#737373/#3773DB 仅用于强调场景 |
| TC-4-08 | P2 | 色值与 token 对应 | 线条色取自 @line1-x token，与 TC-1-02 一致 |

## TC-6 图标规范

**规范值速查（「图标」页，共 804 个图标）：**

- 单色图标：24×24 线性网格，颜色随文字色
- 尺寸场景：导航/菜单 16~20px；列表行内 16px；空状态插画 48~80px
- 业务彩色图标从图标库按名称取用，不得自绘近似图形

| 编号 | 优先级 | 检查项 | 预期结果 |
|---|---|---|---|
| TC-6-01 | P0 | 单色 icon 用 currentColor | 内联 SVG 使用 currentColor，hover/禁用时随文字色同步变化 |
| TC-6-02 | P0 | 图标 24 网格基线 | 基准图标按 24×24 viewBox 缩放，无模糊/变形（非整数缩放需视觉抽查） |
| TC-6-03 | P1 | 尺寸场景正确 | 导航 icon 16~20px、列表行内 16px、按钮内 icon 与字号一致、空状态 48~80px |
| TC-6-04 | P1 | 彩色业务图标来源 | 零部件采购/停车位申请/党群工作等彩色图标与文件格式图标从设计稿图标库导出（SVG/PNG @2x），不得手绘替代 |
| TC-6-05 | P1 | 图标与文字间距 | 图标右侧与文字间距遵循所属组件规范（按钮内 4px、菜单项按导航规范） |
| TC-6-06 | P2 | 图标语义一致 | 同一操作在不同页面使用同一图标（如"刷新"全站同一图形） |

## 建议的执行方式

1. **静态审查**：对 tokens.css / 组件样式做 token 化与色值比对（TC-0-01、TC-1 系列）
2. **DevTools 计算样式抽查**：逐组件核对尺寸/间距/字号（TC-2/3/4/5 系列）
3. **交互遍历**：脚本或手动触发 Normal→Hover→Click→Disabled 四态截图比对（TC-5-03~06）
4. **主题矩阵**：7 套主题 × 关键组件回归（TC-0-03、TC-5-16）
