## 0. 主题体系(总则)

- 系统提供 **6 套主题**:蓝 / 黄 / 紫 / 翠青 / 红 / 碧青。~~绿~~ **已删除(人工裁决:删除绿色主题)**。
- 选定主题后,该主题的 **主色序列** 与 **帮助色板** 生效;其余中立色、辅助色(成功/警告/错误/紫)全主题共享。
- **辅助色中唯一随主题变化的是「帮助」组**:
  - **青色系帮助仅在基础色为蓝色(蓝主题)时作为「帮助」生效**
  - 其他主题 → 帮助 = 蓝色系(与蓝主色序列同值)
  - 其他主题页出现的青色系色板**归属「其他」组**(人工裁决,非第二帮助组)

## 8. 间距规范 ✅

- 梯度:**Sn = 4px × n**(S1~S20 = 4→80px);常用 S6=24 / S4=16 / S3=12 / S2=8
- 建议:组件间距 8px;输入框内容 padding 12px;按钮左右 padding 16px(与按钮批注一致)
- Padding(L/R/T/B):页面内容 24/24/16/24;弹窗 24/24;卡片 16×4;输入框内容 12/12/**6/6**(6px 为设计稿明示的非 4 倍数豁免)
- 弹窗阴影:`0px 1px 20px 0px rgba(0,0,0,0.08)`
