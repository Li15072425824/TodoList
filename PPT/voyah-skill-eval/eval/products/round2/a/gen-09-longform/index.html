岚图 Voyah Design 组件使用手册

更新时间：2026-11-10 | 作者：设计系统团队 | 版本 v2.4.1

本文档面向前端开发与交互设计师，旨在统一岚图数字化产品的视觉与交互规范， 所有组件均基于人工验收冻结的基线 spec-gallery.html 落地实现。

一、设计原则

岚图 Voyah Design 以「简洁、克制、高效」为核心设计原则，在视觉表达上追求层次分明、 重点突出，在交互体验上强调一步到位、减少用户思考成本。每一个组件的诞生， 都需要经过需求分析、方案评审、可用性测试和工程验收四个阶段，确保从设计到落地的一致性。

在颜色体系中，我们采用蓝主题为主色系，辅以成功、警告、错误、帮助、紫色五种语义色， 并通过五级文字、五级线条、三级填充构建完整的视觉层级。所有 token 均经过 WCAG 2.1 对比度校验，确保在正常视力和色弱场景下均可清晰辨识。

在间距体系中，我们遵循 4px 基线网格，所有元素的内外边距均为 4 的倍数， 从 S1（4px）到 S20（80px）共二十级，覆盖从组件内间距到页面留白的全部需求。 这种统一的节奏让页面呼吸均匀，信息密度可控。

提示：在实现组件时，请优先引用 tokens.css 中的 CSS 变量， 避免在业务代码中硬编码色值或尺寸，以便后续主题切换与统一迭代。

二、基础组件规范

基础组件是构成页面的最小单元，包括按钮、输入框、卡片、标签、提示、开关、 复选框、单选框、头像、徽标、标签页、分段控制器等十二类。每一类组件都定义了 默认、悬浮、按下、禁用四种状态，以及大、中、小三种尺寸，确保在不同业务场景下 都有对应的视觉表达。

按钮是交互频次最高的组件之一，我们规定按钮宽度一律随内容由 padding 撑开， 不做固定宽度。主按钮用于确认、提交等正向操作；次要按钮用于取消、返回等中性操作； 描边按钮用于次级强调；危险按钮用于删除、解除等不可逆操作；提示按钮用于引导用户注意； 反白按钮仅用于深色衬底区域。

输入框的内容内边距固定为上下 6px、左右 12px，其中纵向 6px 为设计稿明示的豁免值， 其余场景均遵循 4 的倍数原则。带前后缀图标的输入框应使用 flex 内层布局， 不得通过扩大右内边距的方式让位图标，以保证在不同语言、不同字号下的对齐一致性。

卡片组件采用 8px 圆角、1px line-1 边框、16px 内边距的标准配置， 头部与内容区之间通过一条 1px 的 line-1 分割线过渡。卡片标题使用 16px / 24px 的 模块小标题规格，字重 600，颜色为 text-title。

备注：所有按钮必须携带 .vx-btn 基础类 + 类型类 + 尺寸类， 状态样式由 tokens.css 统一提供，禁止在业务代码中手写 hover / active / disabled 效果。

三、AI 对话组件规范

AI 对话组件是岚图智能助手产品线的核心视觉容器，包含气泡、输入发送框、 会话列表、欢迎语、提示集、思维链、通知卡片等七类组件。整体布局采用左侧会话列表 + 右侧对话主区的经典两栏结构，主区顶部为欢迎语与快捷提示，中部为消息流， 底部为发送输入框。

对话气泡区分 AI 消息与用户消息两种方向：AI 消息居左，头像为岚图品牌主色填充， 气泡内容区使用 fill-3 灰色填充，圆角 12px，内边距 12px 纵向 / 20px 横向； 用户消息居右，头像为灰色背景，气泡内容区使用主色填充、白色文字，保持与 AI 消息的 视觉对称与方向区分。

发送输入框（Sender）采用 20px 胶囊圆角，默认状态为 line-2 边框， 获取焦点后边框切换为主色。输入区域使用 textarea 实现，支持自动换行与高度自适应， 最大高度限制为 6 行（132px），超出后内部滚动。左侧工具按钮（附件、表情等） 使用 Secondary 小按钮，右侧发送按钮使用主色填充。

思维链组件用于展示 AI 的多步执行过程，每一步包含状态指示点与描述文字。 状态分为已完成（绿色）、进行中（主色）、错误（红色）三种，通过 8px 圆点 与左侧对齐，形成可视化的执行进度。思维链整体背景为 fill-3，圆角 8px， 内边距 8px 纵向 / 16px 横向。
