常见问题

还有疑问？这里可能有答案

接入 Nebula 需要多长时间？ +
基础接入通常只需要 30 分钟到 2 小时，取决于你的技术栈和接入深度。我们提供 Web、iOS、Android、小程序等多端 SDK，以及 REST API 和数据导入方案。预置了 200 种常见事件，大部分场景开箱即用。
免费版有什么限制？ +
Starter 免费版支持每月最多 10,000 月活用户、3 个团队成员席位，包含基础事件分析和邮件触达通道。数据保留 90 天。完全足够小团队验证产品和跑通增长流程。
可以随时升级或取消吗？ +
当然可以。你可以在任何时候升级方案，升级后立即生效，我们会按比例计算差价。取消也没有违约金，数据会保留 30 天以便你随时回来。年付方案取消后剩余周期按比例退款。
数据安全和隐私如何保障？ +
我们通过了 ISO 27001 和 SOC 2 Type II 认证，数据全程加密传输和存储。支持私有部署和专属集群，企业版可提供 SSO、审计日志和数据驻留选项。所有操作均符合 GDPR 和个人信息保护法要求。
能不能和我们现有的系统对接？ +
Nebula 支持 80 款以上主流工具的双向集成，包括 CRM、客服、支付、数据仓库等。如果你的工具不在列表中，可以通过 Webhook 和 REST API 自行对接，企业版还提供定制集成服务。
有客服支持吗？响应速度怎么样？ +
免费版有社区支持和文档中心；Growth 方案提供工作日 8 小时内响应的邮件和在线客服；企业版配备专属客户成功经理，工作日 2 小时内响应，并提供定期增长咨询服务。
