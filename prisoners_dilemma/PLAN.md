# 囚徒困境实验方案（Prisoner's Dilemma Lab）

> 本目录包含两部分：
> 1. 本文档 —— 实验设计（行为库 × 实验模式 × 控制变量）
> 2. `index.html` —— 可交互 H5 模拟器，直接用浏览器打开即可

## 1. 游戏基础设定

经典收益矩阵（满足 T > R > P > S，且 2R > T + S）：

| | 对方合作 C | 对方背叛 D |
|---|---|---|
| **我合作 C** | R=3（奖励） | S=0（傻瓜收益） |
| **我背叛 D** | T=5（背叛诱惑） | P=1（互相惩罚） |

- **博弈轮数**：默认 200 轮，可调 10–2000
- **噪声 ε**：每轮以小概率动作被"误执行"（想合作却背叛），模拟真实误解
- **随机种子**：固定种子可复现每一次实验

## 2. 行为（策略）库——实验的核心变量

| 策略 | 行为规则 | 行为特征 |
|---|---|---|
| Always Cooperate | 永远合作 | 无条件善良 |
| Always Defect | 永远背叛 | 无条件恶意 |
| Random | 50/50 随机 | 不可预测 |
| Tit-for-Tat (TFT) | 首轮合作，之后复制对方上一轮动作 | 善良、可激怒、立刻报复 |
| Tit-for-Two-Tats (TF2T) | 连续被背叛 2 次才报复 | 善良 + 宽容 |
| Grudger | 一旦被背叛，永远背叛到底 | 善良 + 零宽容 |
| Pavlov | 上轮结果好（R/T）重复自己动作，差（P/S）就换 | 赢留输变 |
| Prober | 开局 D,C,C 试探；对方全程合作则剥削，否则打 TFT | 善良但爱占便宜 |
| Joss | TFT 但 10% 概率偷偷背叛 | 带噪声的剥削者 |

## 3. 页面里的三种玩法

1. **对战实验**：任选两个策略对战，观察累计得分曲线、合作率曲线、逐轮动作时间线 —— 回答"哪种行为风格在单挑中胜出"
2. **全场锦标赛**（Axelrod 式）：9 种策略两两配对（含自己 vs 自己）打满轮数，按平均每轮得分排名 —— 回答"混合环境中哪种行为整体最优"
3. **历史记录**：每次执行（对战 / 锦标赛）的结果自动保存到浏览器 localStorage，可回看、可删除、可导出 JSON

## 4. 关键控制变量

- **轮数**：50 / 200 / 1000 —— 短博弈剥削者占便宜，长博弈善良策略反超
- **噪声 ε**：0% / 5% / 10% —— 无噪声时 TFT 冠军；有噪声时 TFT 陷入互相报复死循环，宽容的 TF2T 和 Pavlov 反超
- **收益矩阵**：改大 T（背叛诱惑），观察合作率崩塌
- **宽容度**：TFT vs TF2T vs Grudger 对比

## 5. 预期结论（实验要验证的假设）

1. 单轮博弈唯一理性解是背叛；重复博弈里"善良、可激怒、宽容、清晰"胜出
2. Always Cooperate 是烈士——总被剥削者垫底
3. Always Defect 短期占优，长期被孤立，全场 D 时人人拿 P=1 惨分
4. 报复要"及时"但"有限"：噪声下 TFT 太敏感，TF2T 最稳
5. 合作是演化稳定但脆弱的均衡

## 6. 使用方法

```bash
open prisoners_dilemma/index.html
```

无需服务器、无依赖，全部逻辑在浏览器本地运行；数据保存在 localStorage（key: `pd_lab_runs_v1`）。
