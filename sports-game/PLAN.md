# 领跑人生 —— 运动教育养成游戏（Pace for Life）

> 本目录包含两部分：
> 1. 本文档 —— 游戏设计（数值系统 × 训练库 × 事件库 × 知识图鉴）
> 2. `index.html` —— 可交互 H5 养成游戏，直接用浏览器打开即可

**定位**：玩家扮演跑步教练兼经纪人，培养一名运动员从「新手跑者」一路练到「全马完赛者」。通过训练安排、随机事件抉择、比赛日验收，把真实运动科学知识（配速、热身、拉伸、渐进超负荷、负荷管理、恢复）自然嵌入玩法——选对有奖励，选错有惩罚并弹出科普解释。

## 1. 游戏基础设定

核心循环以「训练周」为单位：

```
周日晚上：安排下周 7 天训练计划（从训练库点选填入 7 个槽位）
    ↓
逐日推进：执行当天训练（约 72% 天数触发「执行情境题」）→ 掷事件（约 50% 天数，已有执行题时降至 28%）
    → 玩家选择 → 结算当日数值
    ↓
第 7 天结束：身体反馈弹窗（人形图高亮不舒服 / 变强的部位，带动画）
    → 周复盘界面（负荷 vs 慢性负荷、属性增量、执行决策正确率、教练评语）
    ↓
满足条件后可报名「测试/比赛日」→ 达标升阶 → 解锁新训练 / 事件 / 知识卡
```

游戏体验明确分为两个阶段：**规划**（周日晚安排 7 天课表）与**执行**（逐日推进时回答训练中的真实决策）。
规划考的是「练什么、练多少」，执行考的是「怎么练」——动作标准、拉伸时长、配速控制、跑中突发状况。

运动员初始属性（0–100，体重单位 kg）：

| 属性 | 初始值 | 说明 |
|---|---|---|
| 耐力 endurance | 20 | 主成长轴，升阶硬门槛 |
| 速度 speed | 20 | 间歇/门槛跑成长，影响比赛配速 |
| 力量 strength | 15 | 力量训练成长，加每日恢复 |
| 柔韧 flexibility | 15 | 拉伸成长，加每日恢复、降受伤率 |
| 技术 technique | 15 | 跑姿/核心成长，影响比赛配速与跑动收益 |
| 疲劳 fatigue | 0 | 每日训练累积、休息恢复，超阈值提升受伤风险 |
| 心情 mood | 70 | 影响训练收益系数；单调训练、疲劳过高会下降 |
| 体重 weight | 68 | 影响跑步收益与比赛配速 |
| 受伤 injury | 无 | 轻伤 3–7 天 / 重伤 14–21 天，期间强制只能休息/拉伸/交叉 |

### 核心数值公式

```js
// 训练收益（递减曲线：属性越高收益越低，120 时归零；GAIN_SCALE=0.35 控制整体节奏）
gain = base × 0.35 × (1 − attr/120)
     × (mood ≥ 70 ? 1.1 : mood ≥ 40 ? 1.0 : 0.8)      // 心情系数
     × clamp(1 − fatigue/150, 0.3, 1)                  // 疲劳惩罚
     × 跑步类额外 × clamp(68/weight, 0.85, 1.15)        // 体重影响跑步收益

// 疲劳累积
fatigue += load × 1.15 × (1 − endurance/250)

// 每日恢复
recovery = 6 + (昨晚睡好 ? 4 : 0) + (休息日 ? 8 : 0)
         + flexibility/40 + strength/50

// 每日受伤概率（教学核心：ACWR 急性:慢性负荷比）
acute   = 本周已累计负荷
chronic = max(60, 近 4 周周均负荷)
risk = 0
if (fatigue > 60 + stage×4)  risk += (fatigue − 60 − stage×4) × 0.004
if (acwr > 1.3)              risk += (acwr − 1.3) × 0.15    // 冒进加量 = 高危
if (flexibility < 30)        risk += 0.01
// risk ≥ 0.20 → 重伤（14-21 天）；更低 → 轻伤（3-7 天）

// 比赛配速（秒/公里）
pace = 560
  × (1 − endurance/400 − speed/500 − technique/500)
  × (1 + 0.25 × (距离km/42.195) × (1 − endurance/100))   // 距离越长越吃耐力
  × (1 + fatigue/250)          // 带疲劳参赛必崩（教赛前减量）
  × (mood < 40 ? 1.03 : 1) × (1 + (weight − 62)/300)
  × (赛前减量 taper ? 0.98 : 1)

// 心情
连续两天同类型训练 −5（单一枯燥）；完成计划 +3；里程碑 +10；事件增减

// 体重（周结算）
有氧总负荷 ≥ 80 → −0.3/周；力量总负荷 ≥ 60 → +0.2/周
```

## 3. 阶段升阶（5 阶段，比赛日验收）

| 阶段 | 称号 | 比赛日条件 | 解锁内容 |
|---|---|---|---|
| 0 | 新手跑者 | —（初始） | 轻松跑/徒手力量/核心/拉伸 |
| 1 | 5km 完赛者 | 5km ≤ 35:00，耐力≥35，无伤 | 长距离/门槛跑/交叉训练；事件池扩充；疲劳耐受+4 |
| 2 | 10km 挑战者 | 10km ≤ 1:12:00，耐力≥48，速度≥36 | 间歇跑/杠铃力量；高温/比赛策略事件；疲劳耐受+4 |
| 3 | 半马跑者 | 半马 ≤ 2:20:00，耐力≥65 | 25km+ 长距离；配速策略事件；疲劳耐受+4 |
| 4 | 全马跑者 | 全马 ≤ 4:30:00，耐力≥85，技术≥55 | 终局：赛后复盘页 + 全图鉴成就统计 |

- 比赛日每周日可报名（可选），赛前一周负荷下降（taper）可获成绩 buff——教学点。
- 升阶后：基础长距离 +5km、疲劳阈值 +4、解锁对应训练/事件/知识卡。

## 4. 事件库（24 个，四类）

事件结构：`{id, 类别, 权重, 最低阶段, 触发条件, 标题, 文本, 选项[{标签, 数值效果, 后果文案, 关联知识卡}]}`。按权重加权抽取，每事件每周至多触发 1 次。

**天气类（6）**：突降大雨（照常跑 / 跑步机 / 改休息）、高温预警（清晨 / 傍晚 / 硬扛——中暑风险）、寒冷天（热身时长选择——冷身拉伤风险）、大风逆风、雾霾天（改室内）、雨后湿滑（赶时间摔倒判定）。

**身体类（6）**：次日肌肉酸痛 DOMS（硬练 / 换轻量 / 完全休息）、膝盖刺痛（坚持→重伤概率 / 休息+冰敷 RICE）、感冒前兆（带病训练→加重 / 休息——免疫窗口期）、睡不好（调低强度）、脚上水泡（处理问答）、力量后 48h（练同一肌群 / 换部位——肌肉恢复）。

**生活类（6）**：临时加班（压缩训练 / 熬夜补练 / 调休）、朋友聚会（豪饮 / 适度 / 拒绝）、熬夜看球、家人支持（好事件）、深夜美食、新跑鞋（未磨合硬穿→水泡）。

**教练问答类（4，纯知识问答）**：5km 测试配速选择、热身时机（动态 vs 静态）、补水时机、加量幅度（10% 原则）。答对 +心情 +知识卡；答错 −小心情，但仍有科普解释（教育优先）。

## 5. 训练执行情境题库（45 题，按训练类型索引）

执行阶段不是自动结算：每天训练有约 72% 概率按当天训练类型抽一道「执行情境题」，以弹窗形式模拟训练进行中的决策。弹窗先播放训练进度（热身 → 主训练，进度 55%），再抛出问题；选择后展示后果与知识卡，进度补到 100%。每周内同题不重复，题目效果计入当日收益/疲劳/心情/受伤风险。

题库结构：`{id, train:[训练id], icon, weight, cond?, title, text, options:[{label, fx, risk?, after, kb, correct?}]}`

| 训练类型 | 题数 | 典型场景 |
|---|---|---|
| 拉伸/瑜伽 | 6 | 拉伸顺序、腘绳肌姿势（弓背 vs 背部中立）、只有 3 分钟怎么拉、呼吸、下犬式手腕痛、拉到什么程度 |
| 轻松跑 | 6 | 配速该多快、**天气好已跑 5km 还想加 3km**、岔气、红绿灯、步幅步频、跑中变累 |
| 长距离跑 | 6 | 长跑配速、90 分钟以上补给、中途如厕、状态好想延长、后半程掉速、跑后恢复 |
| 门槛跑 | 5 | 强度体感、20 分钟怎么跑、热身、配速漂移、频率 |
| 间歇跑 | 5 | 组间休息、最后一组冲不冲、热身、频率、小腿发紧 |
| 力量训练 | 6 | 热身组、深蹲膝内扣、渐进超负荷、练到力竭、杠铃呼吸、力量与跑步排期 |
| 核心训练 | 4 | 平板支撑塌腰、频率、时长 vs 质量、核心对跑者的意义 |
| 交叉训练 | 4 | 强度控制、能否替代跑步、座椅高度、受伤期安排 |
| 完全休息 | 3 | 休息日做什么、几点睡、怎么吃 |

设计原则：

- **正确选项有正反馈**（属性/心情 +），**错误选项有真实代价**（疲劳、风险、心情 −），并附解释——即使选错也完成科普。
- 题目对应已有关联知识卡（如 10% 原则、ACWR、配速分级、步频、RICE、睡眠），事件结算时同步解锁。
- 周复盘新增「执行阶段决策 N / M 正确」统计，把「会计划」与「会执行」分开反馈。
- 题库每次 WEEK 轮换（`weekExecUsed`），且通过 `cond` 可扩展为按周负荷/阶段动态触发。

### 选择判定与周身体反馈

**选择判定**（有唯一正确答案的题）：选中最优 → 绿色弹层「🎉 恭喜，这是最优选择！」；选非最优 → 红色弹层列出真实代价（如「疲劳 +2」「心情 −1」「当日受伤风险 +4%」「当晚睡眠恢复 −4」），并揭示「更优解：…」。没有唯一答案的生活事件只展示后果，不强行判对错。

**周身体反馈**：第 7 天训练结束后、周复盘之前弹出人形反馈图。

- SVG 人形按部位分区（头/胸/核心/腰/髋/大腿/膝/小腿/踝/脚/手臂），不舒服部位红色脉冲、变强部位绿色脉冲，整体做轻微呼吸动画。
- 判定依据：现有伤病 > 本周 ACWR > 执行阶段失误（加量、动作变形、拉伸不到位）> 高疲劳/柔韧不足；无负面信号时按跑步/力量/拉伸完成度给出「腿部更有力」「上肢和核心更稳」「髋部更灵活」。
- 每个部位配一句口语化感受（「我感觉自己变强了！」「膝盖有点发紧…」）和一条可执行建议，最多 3 个不适部位 + 1 个正反馈部位。
- 反馈只作为训练信号，弹窗底部注明不构成医疗建议。

## 7. 页面与玩法

- **训练周（主界面）**：7 天计划网格（点选训练，tooltip 显示负荷与收益）→「开始本周」→ 日志流式推进，事件暂停弹窗
- **运动员**：五维属性条 + 疲劳/心情/体重 + canvas 8 周负荷柱状图（急性 vs 慢性双线，ACWR 可视化）+ 受伤状态
- **图鉴**：知识卡片网格，按 tag 筛选
- **记录**：历史比赛成绩与阶段达成记录
- 弹窗：执行情境 modal（训练进度条 + 场景题 + 2~3 选项 + 结果判定 + 代价 + 知识卡）、事件 modal（emoji 场景 + 2~3 选项 + 后果 + 知识卡）、身体反馈 modal（SVG 人形高亮 + 部位动画 + 感受文案）、周复盘（执行正确率 + 教练评语）、比赛日（逐公里动画）
- 移动端 375px 可用，支持暗色模式

## 8. 预期教学效果

玩过之后应该能回答：

1. 为什么每周加量不能超过上周的 10%？（10% 原则 + ACWR）
2. 跑前该做动态热身，跑后静态拉伸——为什么时机不同？
3. 膝盖刺痛时该「坚持练完」还是「停练 + 冰敷」？（RICE）
4. 为什么练完腿第二天不能立刻再练腿？（48h 肌肉恢复 + DOMS）
5. 高温/寒冷/雨天怎么调整训练？
6. 为什么比赛前一周要减量？（taper）
7. 为什么只有跑步不练力量会瓶颈？（力量对跑者的价值）
8. 为什么带疲劳参赛成绩会崩？（疲劳对配速的惩罚）
9. 拉伸每个动作该保持多久、拉到什么程度？（20–30 秒、3–5 分牵拉感）
10. 天气很好、已经跑了 5km，还想加 3km——能加吗？怎么加？（降速 + 计入周总量 + ACWR）
11. 跑步中岔气、长跑补给、步频步幅这些具体场景该怎么做？

## 9. 使用方法

```bash
open sports-game/index.html
```

- 存档：localStorage `sports_coach_save_v1`（每日结算自动存，含版本号）
- 知识图鉴：localStorage `sports_coach_kb_v1`（跨周目保留）
- 平衡性自测：控制台 `__debug(40)` 模拟 40 周（`__debug(25, 'hard')` 走蛮练路线）
  - 实测：科学路线约 23-28 周通关全马、0-2 次轻伤（含执行题全答对的理想情况）；蛮练路线 7-11 次受伤（含重伤）、心情崩盘、25 周仍卡在 5km 阶段
