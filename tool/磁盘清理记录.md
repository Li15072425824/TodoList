## 五、通用排查命令备忘

```bash
df -h /System/Volumes/Data              # 看数据盘整体
du -sh ~/* | sort -rh | head -20        # 主目录一级目录排序
du -sh ~/.[a-zA-Z]* | sort -rh | head -20   # 隐藏目录排序（孤儿数据常在这）
du -sh ~/Library/* | sort -rh | head -15    # Library 排序
du -sh ~/Library/"Application Support"/* | sort -rh | head -15
du -sh ~/Library/Containers/* | sort -rh | head -8
# 找 WorkRep 下的依赖目录（可删可重建）：
find ~/WorkRep -maxdepth 4 \( -name node_modules -o -name .venv -o -name venv \) -type d -prune | xargs -I{} du -sh {} | sort -rh
```

**排查思路**：先 `df` 看总量 → `du` 逐层下钻找大户 → 区分三类数据：**缓存（随便删，自动重建）**、**孤儿数据（应用已卸载就删）**、**在用数据（保留或走应用内清理）** → 删除前确认对应应用未在运行、目录边界得到确认（本轮明确：WorkRep 不动，A2UI 经确认例外删除）。
