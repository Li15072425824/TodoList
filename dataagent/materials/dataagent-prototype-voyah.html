指标定义

按「数据源 → 数据集 → 维度 → 指标」逐层定义：先接入数据源，再由资产表或 SQL 创建数据集，绑定分析维度后定义指标，发布即对 Agent 开放

内表　数据已导入 StarRocks / Doris，查询性能最优 外表　以外表模式直连外部库，不做数据搬运 数据源　指标平台的数据底座，指标必须挂靠在某个数据源上
⌕
数据表创建　直接选择数据源下的资产表 SQL 创建　自定义 SQL，数据读取至 OLAP 数据集关系　通过关联字段形成数据模型，是指标与维度关联的基础
⌕
字段映射　由数据集中的字段直接生成 自定义表达式　由表达式派生的维度 枚举维护　手工维护的枚举值维度
⌕
基础指标　直接聚合数据集字段（SUM/AVG/COUNT） 派生指标　基础指标 + 时间限定 + 业务限定 + 衍生方式 复合指标　多指标四则运算组合（如 销售 − 退货）
