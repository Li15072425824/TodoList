## 核心结论

### 1. 这是什么

- **单文件交互原型**：HTML+CSS+JS 全部内联（720KB / 9636 行），无后端、无真实数据，所有数据是 JS 里的 mock（`METRIC_LIST`、`SESSIONS`、`TREES`、`MCP_CAPS` 等）。
- 定位：**「DataAgent · 指标本体驱动的数据分析智能体」**，演示租户是「岚图汽车 · 数据团队（管理员）」。
- 顶部可切换 **业务视角 / 数据管理视角** 两种角色。

### 2. 核心理念（一句话）

**指标本体是唯一权威语义层**：指标口径（计算公式、维度、别名、版本、血缘）只维护一份，Agent 问数、指标树归因、看板、Semantic API、MCP 对外服务全部消费同一套口径 —— 保证「人和 Agent、内部和外部取到的数永远一致」。

### 3. 信息架构（侧栏三区）

**① 智能问数（面向分析人员）**
| 模块 | 要点 |
|---|---|
| 任务 | 「对话即任务」主工作台。任务类型 5 种：问数(data)、查资产(asset)、看质量(quality)、洞归因(attribution)、思维洞察(think)。AI 回答自带：指标卡 + **口径说明** + 引用溯源 + 后续追问建议 |
| 空间 | 多人协作：目标/计划/任务/作品/知识/归因模型/成员都围绕会话沉淀 |
| 对话建指标 | 自然语言建指标。新建流程：**查重 → 数据支撑 → 维度补充 → 加速判断**；变更流程：选指标 → 改口径 → **影响面分析** → 发版 |
| 知识·思维·技能·工具 | Agent 能力四载体：知识（18 条，个人/企业两级，分 SOP/业务规则/术语口径/分析结论）、归因模型（6 个，思路复用）、思维（方法论 18 + 案例 25，按 **L1-L4 认知层级**）、技能（12）、工具（9） |
| 作品 | 产出沉淀分发：数据看板 / 归因报告 / 数据画像 |

**② 语义资产与消费（面向数据团队）**
- **指标定义**：四层链路 `数据源 → 数据集 → 维度 → 指标`；指标分基础（直接聚合）/派生（+时间/业务限定）/复合（四则运算）。
- **指标中心**：47 个指标，T1-T4 等级。指标详情抽屉 6 个 tab：概览（含**别名/同义词**，服务问数语义匹配）、计算定义、**血缘**（影响分析）、监控与加速、**在指标上试问**（锁定指标上下文直接问答）、变更与版本（审批、回滚、上游变更处理）。
- **指标树**：核心指标为根，按指标/维度拆解，配计算关系与目标值，发起**贡献度归因**（如：销售 +2.37% = 客单价 +118%、客户数 -18%）。
- **指标加速**：物化加速 —— 高频指标预计算成物化表（命中率 86%），含周期实例、补数、DAG、监控告警；对话取数会回报物化命中状态，未命中自动降级明细查询。
- **资源目录**：数据源 → 资产表 → 关联指标；数据质量体检（6 维打分给可用性结论）。

**③ 集成与调用（面向生态）**
- **API 集成服务**：Semantic API 双向 —— 入向（DataAgent 读数据）/ 出向（语义结果分发给外部系统），共用同一语义层。
- **MCP 服务**：把能力标准化为 **27 个 MCP 工具、6 大能力域**（问数取数 / 归因分析 / 指标语义 / 数据资产 / 知识与模型 / 任务与作品），外部 Agent（Claude Code、Cursor、企微 Copilot）配置一次即可复用同一口径，无需自己写 SQL。

### 4. 值得注意的产品闭环（原型的「魂」）

1. **语义闭环**：指标定义 → 物化加速 → 问数/看板/API/MCP 全走同一本体。
2. **知识沉淀闭环**：对话中 AI 识别可复用 SOP → 主动问询「是否沉淀为知识」→ 个人知识（保存即生效）/ 企业知识（管理员审核后生效）→ 归因模型与思维方法论在后续对话中召回复用。
3. **治理闭环**：审批、版本对比、上游变更影响分析、T1 指标双人复核、「对 Agent 开放」按指标授权。
4. **分析范式**：问数 → 归因（指标树 + 归因模型）→ 沉淀（知识/模型）→ 发布（作品/API/MCP）。

### 5. 技术层面注意点

- 这是**演示原型，非可运行产品**：交互大部分走 `toast()` 假反馈，数据写死。
- mock 数据集中在 3020 行以后的 `<script>`，想看某模块的产品逻辑可直接搜对应 const（`SESSIONS` 4739 行、`TREES` 7056 行、`MCP_CAPS` 6732 行、`KNOWLEDGE` 7756 行、`PROJECTS` 9197 行）。
